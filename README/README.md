<h2 id="info">Descrição do Projeto</h2>


 Sistema pensado para gerenciar receitas e despesas de forma rápida e intuitiva. Com o Sistema E-Supply, você pode registrar, consultar, editar, apagar e filtrar todas as suas movimentações financeiras em um só lugar. Ideal para organizar suas finanças pessoais ou de seu pequeno negócio.

<h2 id="info">Objetivo do Projeto</h2>

 Desenvolver uma ferramenta digital simples, intuitiva e eficiente para a gestão de recursos, que capacite usuários a controlar suas receitas e despesas pessoais ou de pequenos negócios. O projeto visa proporcionar clareza e organização sobre a saúde financeira, facilitando a tomada de decisões e o planejamento.

<h2 id="tech">Tecnologias</h2>

- Tailwind
- JavaScript
- MySQL
- Docker
